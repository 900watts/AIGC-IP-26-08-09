## 🔁 Regeneration tips

- If 莞仔's face drifts between scenes: attach the reference image every time and put it as the **first** input image.
- If the cap emblem disappears: change `a small green longan-leaf emblem` → `a clearly visible green longan-leaf emblem on the front center of the cap`.
- If colors drift toward purple: add to negative prompt: `purple, blue-purple, lavender, lilac, magenta`.
- If mascot looks too 3D / rendered: add to negative prompt: `3D, render, CGI, octane, unreal engine, photorealistic, plastic`.
